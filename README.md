# Pressure Quotient: IPL Toss Psychology & Statistical Analysis (2008–2026)

An end-to-end data analytics and behavioral science project examining whether T20 cricket captains suffer from cognitive biases (availability heuristic, loss aversion, herd mentality) when winning the toss.

---

## 💡 Executive Summary & Key Finding

> "The rise in field-first preference follows a strong linear trend ($r = 0.71, p = 0.0007$), yet this increasing consensus has not improved toss-to-win conversion ($r = -0.09, p = 0.71$). This suggests diminishing strategic returns — the more universal the field-first orthodoxy becomes, the less predictive it is, consistent with the efficient market hypothesis applied to tactical decision-making in T20 cricket."

---

## 📊 Core Statistical Highlights

* **Toss Impact Effect Size:** Weak overall association ($\chi^2(1) = 7.07, p = 0.008$, Cramér's $V = 0.077$).
* **Fielding Choice Premium:** ~8 percentage point win advantage (57.1% win rate fielding first vs. 48.8% batting first).
* **Behavioral Drivers:** Decision-making is heavily influenced by **Availability Bias** (dramatic chasing wins are more memorable) and **Loss Aversion** rather than raw statistical odds.
